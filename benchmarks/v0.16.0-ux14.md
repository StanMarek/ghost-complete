# v0.16.0 ux-14 Native Tool Providers

Date: 2026-05-11

## Corpus

Regenerated with:

```sh
npm --prefix tools/fig-converter run convert -- --output ../../specs
```

The converter run produced 715 specs. This PR commits the 711-spec scoped
corpus that stays under the existing embedded heap budget; the large
gcloud-sized additions remain deferred until the compression phase.

Committed corpus summary:

- Specs: 711
- Native Rust generators: 621
- Provider-dispatched generators: 448

- Requires JS generators: 2,787

## Benchmark Coverage

`crates/gc-suggest/benches/suggest_bench.rs` now includes
`engine_suggest_sync` route benchmarks for the ux-14 providers:

- `cargo run --bin`
- `npm uninstall`
- `docker stop`
- `kubectl get`
- `tmux switch-client -t`
- `systemctl start`
- `brew install`
- `chown`

These cases measure sync spec resolution and provider scheduling. Provider
subprocess parsing is covered by provider integration tests.
