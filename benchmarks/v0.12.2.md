# Benchmarks - v0.12.2

Date: 2026-05-04
Platform: macOS (Apple Silicon)
Command: `cargo bench`

Comparisons reference the local Criterion baseline from v0.12.1. This is a
patch release for automatic popup triggering (#105). The release touches
PTY/proxy trigger behavior plus spec directory handling that landed on master
before the release.

Gnuplot was not installed; Criterion used the plotters backend.

## Summary

`cargo bench` completed successfully. Most hot-path benchmarks moved within a
low single-digit band relative to the current baseline. Criterion flagged a set
of 1-3% regressions, one spec-loading improvement, one memory-walk improvement,
and one notable filesystem/alias-heavy regression:

- `engine_suggest_sync/alias_hit_multi`: 1.5887 ms, +14.048% vs baseline.
- `spec_loading/load_717_specs`: 284.28 ms, -1.9002% vs baseline.
- `memory/embedded_specs_heap_walk`: 4.2918 ms, -3.2499% vs baseline.

The multi-alias benchmark has historically been sensitive to tmpdir and APFS
cache state; it remains far below interactive latency budgets but should be
watched in the next release.
