# Benchmarks - v0.16.0

Date: 2026-05-13
Platform: macOS 26.4.1 (Apple Silicon, arm64)
Rust: rustc 1.95.0 (59807616e 2026-04-14)
Command: `cargo bench`

Comparisons reference the last checked-in full release benchmark note,
v0.15.0. v0.16.0 is a large runtime release: native completion migration
phases, zstd-compressed embedded specs, AWS SDK provider plumbing, native tool
providers, install mirror refresh, and config editor updates all landed in the
cycle.

Gnuplot was not installed; Criterion used the plotters backend.

## Summary

`cargo bench` completed successfully. The common hot-path groups are flat to
low-single-digit movement against v0.15.0: parser, fuzzy ranking, transforms,
priority sort, memory, and core `engine_suggest_sync` all remain comfortably
inside the release budget.

The synchronous keystroke path remains healthy: command-position and static
subcommand suggestions stay under 18 us, filesystem and multi-alias paths stay
near 1.1 ms, and 10k priority sorts remain below 1 ms.

The v0.16.0-specific provider route benches are also within budget. Most native
provider dispatch routes are 4.5-13.8 us, with `dscl` users at 1.06 ms. The AWS
SDK route remains split as expected: cold route including AWS spec first touch
is 337.94 ms, while the warm route is 1.32 us and improved versus the local
Criterion baseline.

Lazy-load first-touch numbers moved up for AWS paths versus v0.15.0
(`first_get_aws` +11.93%, `evict_then_get_aws` +12.90%), but the absolute
numbers remain below the ux-12b 200 ms cold decompress+parse acceptance bar.
Warm lookups are still tens of nanoseconds.
