Comparisons are Criterion's local baseline from the previous checked-in run on
this machine. Gnuplot was not installed; Criterion used the plotters backend.

## Summary

ux-10b adds a new helper-lowered JSON path benchmark and lowers 1,558
postProcess generators in the checked-in corpus. The new
`transform_pipeline/helper_lowered_json_path` case runs in ~68.8 us over 200
AWS-style role objects, which is the native replacement for the prior QuickJS
postProcess round trip.

The existing transform benchmarks moved by +2.9% to +5.7%. The synchronous
engine group reported +6% to +23% against the local Criterion baseline, while
absolute medians stayed between ~17 us and ~1.21 ms. The command-position case
had a wide confidence interval and outliers, so treat this as a watch item for
the next full release benchmark run rather than a confirmed algorithmic
regression.
