# Benchmarks — v0.12.1

Date: 2026-05-04
Platform: macOS (Apple Silicon)

Comparisons reference v0.12.0 (`benchmarks/v0.12.0.md`). v0.12.1 is a
patch release: `install-local` warning cleanup in `doctor` / `status`
plus a converter re-run on a handful of specs (#103). No engine, parser,
suggest, or overlay code changed — all groups expected to be flat.

Within run-to-run noise. Corpus size effectively unchanged — the

## Analysis

No engine, parser, suggest, or overlay code changed in v0.12.1. All
keystroke-budget cases sit within ±2% of v0.12.0 baselines — well
inside run-to-run noise on this machine. The two filesystem-walk
benches continue to show APFS-cache variance flagged in v0.12.0; not
release-blocking and not regressed by this PR.

No new benchmark groups this release.
