# Benchmarks - v0.18.0

Date: 2026-06-14
Platform: macOS 26.4.1 (Apple Silicon, arm64)
Rust: rustc 1.95.0 (59807616e 2026-04-14)
Command: `cargo bench`

Comparisons reference the last checked-in full release benchmark note,
v0.17.0. v0.18.0 is a purely additive feature release: two opt-in,
config-gated behaviors — `popup.tab_accepts_top` (accept the top-ranked
suggestion on Tab before any navigation, #150) and
`suggest.match_mode = "substring"` (contiguous-substring filtering instead of
fuzzy subsequence, #149). Both default to the historical behavior, and neither
changes a hot-path algorithm on the default code path, so the expectation
going in was flat-to-noise across every group.

Gnuplot was not installed; Criterion used the plotters backend. Comparisons
are computed against the v0.17.0 report medians (cross-report, not a saved
Criterion baseline), so µs-scale and ns-scale rows carry normal run-to-run
machine variance.

## Summary

`cargo bench` completed successfully. Every hot-path group is flat-to-noise
against v0.17.0: parser throughput, OSC decode, fuzzy ranking, spec loading,
spec resolution, transforms, priority sort, lazy load, and memory all sit
within ~1–3% of the prior release, with no algorithmic regression on any
default code path. The substring match-mode branch is gated behind
`MatchMode::Substring`; the benched fuzzy path is unchanged, which the
fuzzy_ranking and engine_suggest_sync groups confirm.

The standout result is that **all three regressions v0.17.0 flagged for
next-release confirmation reverted**, exactly as that report predicted they
would:

- `engine_suggest_sync/command_position` — v0.17.0 logged +13.40% (19.561 µs)
  with a wide band and "reads as run-to-run variance"; this run lands at
  17.702 µs (**-9.50%**), back in its historical range.
- `provider_route_systemd_units` — v0.17.0 logged +26.52% (5.7510 µs); this run
  is 4.6299 µs (**-19.49%**), fully recovered.
- `provider_route_docker_containers` — v0.17.0 logged +7.21% (5.2252 µs); this
  run is 4.9783 µs (**-4.73%**), recovered.

`provider_route_tmux_sessions` (v0.17.0 +10.14%) settled most of the way back
to +2.65% (11.462 µs) and is logged again for next release.

The honestly-up rows this cycle are the `engine_suggest_sync_token_only`
fixtures, which posted +15–18% but with very wide Criterion confidence bands on
this run (`returns_tokens` measured [158.26 µs, 166.85 µs];
`previous_token_branch` [164.64 µs, 179.07 µs]) — a high-variance sampling run,
not a code change. No token-only JS path changed in v0.18.0; these are flagged
to confirm they revert next release. A scatter of other rows moved +2–3%
(`transform_pipeline/json` +2.86%, `engine_suggest_sync_aws_sdk/cold` +2.81%,
`spec_resolution/with_static_suggestions_tar` +3.02%) — all small-absolute and
inside their bands.

All sub-keystroke paths remain far inside the <50 ms keystroke-to-suggestion
budget (and the <20 ms stretch). Cold AWS first-touch stays below the 200 ms
acceptance threshold.
