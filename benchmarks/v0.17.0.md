# Benchmarks - v0.17.0

Date: 2026-06-07
Platform: macOS 26.4.1 (Apple Silicon, arm64)
Rust: rustc 1.95.0 (59807616e 2026-04-14)
Command: `cargo bench`

Comparisons reference the last checked-in full release benchmark note,
v0.16.0. v0.17.0 is primarily a correctness and hardening release: real clap
subcommands, the zsh/macOS OSC framing sweep, overlay sync-frame
consolidation, static alias parsing, query-aware Homebrew completion, new
macOS-native providers, and CI gate hardening. No hot-path algorithm changed,
so the expectation going in was flat-to-improved across the board.

Gnuplot was not installed; Criterion used the plotters backend. Comparisons
are computed against the v0.16.0 report medians (cross-report, not a saved
Criterion baseline), so µs-scale rows carry normal run-to-run machine
variance.

## Summary

`cargo bench` completed successfully. The hot-path groups are flat-to-improved
against v0.16.0: parser throughput, OSC decode, fuzzy ranking, spec loading,
spec resolution, transforms, token-only fallback, priority sort, and memory
all moved down or held within ~1%.

Notable improvements: full-corpus `spec_loading/load_717_specs` is -5.47%
(144.55 ms → 136.64 ms), `osc7772_decode/1024` is -5.95%, `transform_pipeline/json`
is -4.38%, and the `engine_suggest_sync_token_only` fixtures are all 3.5–5.0%
faster. AWS SDK cold/warm routes are flat (-0.54% / -0.14%), and the lazy-load
AWS first-touch and eviction paths edged down versus v0.16.0.

A few µs-scale rows moved up and are called out honestly rather than buried:
`engine_suggest_sync/command_position` (17.25 µs → 19.56 µs, +13.40%) and three
native-provider routes — `provider_route_systemd_units` (+26.52%),
`provider_route_tmux_sessions` (+10.14%), `provider_route_docker_containers`
(+7.21%). All four have wide Criterion confidence bands on this run
(`command_position` measured [19.167 µs, 19.966 µs]; `systemd_units`
[5.55 µs, 5.94 µs]), are sub-20 µs in absolute terms, and sit far inside the
<50 ms keystroke-to-suggestion budget (and the <20 ms stretch). No hot-path
code in these routes changed this cycle, so these read as measurement noise;
they are logged for the next release to confirm they revert.

The overlay sync-frame consolidation (#138) added three new bench groups —
`bench_popup_render`, `bench_detail_render`, and `bench_full_update` — recorded
here as v0.17.0 baselines for future comparison.
