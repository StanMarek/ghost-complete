# Benchmarks - v0.14.0

Date: 2026-05-08
Platform: macOS 26.4.1 (Apple Silicon, arm64)
Rust: rustc 1.95.0 (59807616e 2026-04-14)
Command: `cargo bench`

Comparisons reference the last checked-in benchmark note, v0.12.3. v0.14.0
prioritizes the current git branch in branch suggestions (#117), so the most
relevant release path is `engine_suggest_sync` plus the git provider ranking
covered by tests.

Gnuplot was not installed; Criterion used the plotters backend.

## Summary

`cargo bench` completed successfully. The keystroke-path benchmarks remain in
the same range as the previous recorded report: command-position and
subcommand suggestions stay under 18 us, and the filesystem/alias cases stay
near 1.1 ms.

Most benchmark groups were flat or improved relative to v0.12.3. The one
notable increase was `memory/embedded_specs_heap_walk` at 10.448 ms versus
4.9427 ms in v0.12.3. This release does not change embedded specs or the heap
walk; keep watching it in the next benchmark run.
