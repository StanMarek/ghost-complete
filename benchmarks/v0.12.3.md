# Benchmarks - v0.12.3

Date: 2026-05-05
Platform: macOS (Apple Silicon)
Command: `cargo bench`

Comparisons reference the local Criterion baseline from v0.12.2. This is a
patch release for deferring automatic popup triggers until the terminal display
has caught up (#107, #108). The release touches PTY/proxy trigger timing.

Gnuplot was not installed; Criterion used the plotters backend.

## Summary

`cargo bench` completed successfully. Most sub-millisecond hot-path benchmarks
were flat or improved relative to the current baseline, but Criterion flagged a
few noisy regressions:

- `fuzzy_ranking/10k_3char`: 1.7277 ms, +43.007% vs baseline.
- `spec_loading/load_717_specs`: 300.71 ms, +5.7804% vs baseline.
- `spec_resolution/deep`: 1.3687 us, +20.048% vs baseline.
- `memory/embedded_specs_heap_walk`: 4.9427 ms, +15.166% vs baseline.

The release change is not in fuzzy ranking, spec loading/resolution, or embedded
spec heap walking. The filesystem and multi-alias engine cases improved
substantially in this run, consistent with the APFS/tmpdir variance noted in
prior benchmark reports. The popup trigger fix does not add work to the
keystroke suggestion path after the display is caught up.
